# TCP 协议

一句话：TCP 是可靠、面向连接的字节流协议，保证顺序和可靠，不保证消息边界。

## 三次握手（建立连接）
```
客户端 SYN → 服务器
服务器 SYN+ACK → 客户端
客户端 ACK → 服务器
```
- 为什么三次不是两次？防止失效的旧连接请求到达服务器，造成资源浪费。

## 四次挥手（断开连接）
```
A FIN → B
B ACK → A
B FIN → A
A ACK → B
```
- 为什么四次？A 发 FIN 表示"我不发了"，但 B 可能还有数据要发，所以 ACK 和 FIN 分开。

## TIME_WAIT
- 主动关闭方进入 TIME_WAIT，等待 2MSL（约 60 秒）
- 作用：确保最后一个 ACK 能重传 + 让旧连接的包消散
- 服务器大量 TIME_WAIT 的解决：SO_REUSEADDR、调整内核参数

## 可靠传输
- 滑动窗口：流量控制
- 拥塞控制：慢启动、拥塞避免、快重传、快恢复
- 确认 + 重传

## 面试高频题
**Q: 为什么握手三次、挥手四次？**
A: 握手：ACK 和 SYN 可合并；挥手：B 收到 FIN 后可能还有数据要发，ACK 和 FIN 要分开。

**Q: TIME_WAIT 作用？**
A: 保证最后一个 ACK 可靠到达 + 让旧连接包消散，防止串扰新连接。
