# 智能指针

一句话：用 RAII 自动管理内存，替代裸指针的 new/delete。

## 裸指针三大问题
1. 忘记 delete → 内存泄漏
2. delete 后还访问 → use-after-free（悬垂指针）
3. 重复 delete → 崩溃

## 三种智能指针
| | 所有权 | 特点 |
|---|--------|------|
| `unique_ptr` | 独占 | 不能拷贝、只能移动，离开作用域自动 delete |
| `shared_ptr` | 共享 | 引用计数，拷贝 +1 析构 -1，归 0 释放 |
| `weak_ptr` | 弱引用 | 不增加计数，解决循环引用 + 观察对象是否存活 |

## 面试高频题
**Q: unique_ptr 为什么不能拷贝？**
A: 独占所有权，拷贝会导致两个指针都以为自己是主人 → 双重 delete。

**Q: shared_ptr 循环引用？**
A: 两个对象互持 shared_ptr，计数永远不归 0 → 泄漏。用 weak_ptr 打破循环（weak_ptr 不增加计数）。

**Q: weak_ptr 怎么用？**
A: `lock()` 返回 shared_ptr（对象还活着）或空（已释放）。muduo 的 Channel::tie() 就用它解决 use-after-free。

**Q: make_shared 和 new 的区别？**
A: make_shared 一次分配对象+控制块（更高效、异常安全）；new shared_ptr 分两次。
