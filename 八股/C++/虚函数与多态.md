# 虚函数与多态

一句话：多态 = 基类指针调虚函数，运行时通过 vptr → vtable 决定调谁。

## 底层原理
- **vtable（虚函数表）**：每个有虚函数的类一张，存虚函数地址，存在静态存储区
- **vptr（虚函数指针）**：每个对象开头隐藏指针，指向所属类的 vtable
- 调用虚函数：vptr → vtable → 函数地址（运行时查表，动态绑定）

## 纯虚函数与抽象类
- `virtual void f() = 0;` 声明纯虚函数
- 有纯虚函数的类是抽象类，不能实例化，子类必须实现

## 面试高频题
**Q: 多态怎么实现？**
A: 虚函数 + vptr 指向 vtable，运行时查表动态绑定。

**Q: 构造函数能是虚函数吗？**
A: 不能。构造时 vptr 还没建立，无法动态绑定。

**Q: 析构函数为什么要虚？**
A: 基类指针 delete 派生类对象时，非虚析构只调基类析构，派生类资源泄漏。只要类可能被继承，析构就应写虚。

**Q: static 函数能是虚函数吗？**
A: 不能。static 没有 this 指针，不参与动态绑定。
