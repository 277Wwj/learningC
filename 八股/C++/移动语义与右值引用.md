# 移动语义与右值引用

一句话：移动 = "偷资源"（O(1)），拷贝 = "复制资源"（O(n)）。

## 核心概念
- **左值**：有名字、能取地址、会存活（`int a`、`string s`）
- **右值**：临时对象、字面量、用完即弃（`Big()`、`42`）
- **右值引用 `T&&`**：专门绑定右值
- **`std::move`**：只是把左值 cast 成右值引用（贴标签），**不移动任何东西**
- **移动构造**：偷指针 + 把原对象指针置 nullptr（防双重释放）

## 面试高频题
**Q: std::move 干了什么？**
A: 它不做任何移动，只是 `static_cast<T&&>`，把一个左值"标记"成右值，让编译器选择移动构造而不是拷贝构造。

**Q: 移动构造为什么加 noexcept？**
A: vector 扩容时，如果移动构造可能抛异常，vector 会退回用拷贝（保证异常安全）。加了 noexcept 才能用高效的移动。

**Q: 规则五（Rule of 5）？**
A: 如果类需要自定义析构/拷贝/移动其中任一个，通常五个都要写全：析构、拷贝构造、拷贝赋值、移动构造、移动赋值。
