# 进程与线程

一句话：进程是资源分配单位，线程是 CPU 调度单位。

## 核心区别
| | 进程 | 线程 |
|---|------|------|
| 资源 | 独立地址空间 | 共享进程内存 |
| 开销 | 创建/切换大 | 创建/切换小 |
| 通信 | IPC（管道、共享内存、socket） | 直接读写共享内存（需加锁） |
| 崩溃 | 互不影响 | 可能带崩整个进程 |

## 线程共享 / 独享
- 共享：堆、全局变量、静态变量、文件描述符、代码段
- 独享：栈、寄存器、程序计数器 PC

## 协程
- 用户态轻量级线程，程序自己调度，切换不经内核
- 切换开销极小，可创建几十万上百万个
- 游戏服务器用它扛高并发

## 面试高频题
**Q: 多线程一定快吗？**
A: 不一定。上下文切换开销 + 锁竞争 + CPU 核数限制，线程数超核数反而变慢。

**Q: 协程和线程区别？**
A: 协程用户态调度、切换不经内核、开销极小；线程内核调度。
