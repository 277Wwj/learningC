# 文件系统

一句话：文件由 inode 描述，读写经页缓存加速，零拷贝避免多余拷贝。

## inode
- 文件元数据（大小、权限、数据块位置），不含文件名
- 文件名存在目录项里，目录项 → inode → 数据块

## 页缓存（Page Cache）
- 读文件时数据先缓存到内存，下次读直接命中，避免反复读磁盘
- 写文件先写缓存，由内核异步刷盘（write-back）

## 零拷贝（sendfile）
- 传统发送文件：磁盘 → 内核缓冲 → 用户态 → 内核 socket 缓冲 → 网卡（4 次拷贝）
- sendfile：磁盘 → 内核缓冲 → 网卡（跳过用户态，2 次拷贝 + DMA）
- 大文件传输用 sendfile 性能显著提升

## IO 模型（面试必背）
| 模型 | 特点 |
|------|------|
| 阻塞 IO | 没数据就卡住 |
| 非阻塞 IO | 没数据立刻返回 EAGAIN |
| IO 多路复用 | 一个线程监视多个 fd（select/poll/epoll） |
| 异步 IO | 内核完成读写后通知（aio） |

## 面试高频题
**Q: 什么是零拷贝？**
A: 减少数据在用户态和内核态之间的多余拷贝，如 sendfile 直接内核到网卡。
