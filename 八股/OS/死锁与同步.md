# 死锁与同步

一句话：死锁 = 多个线程互相等对方手里的锁，谁都动不了。

## 死锁四个必要条件（同时满足才死锁）
1. 互斥：资源一次只能一个线程用
2. 持有并等待：拿着一个锁，还等另一个
3. 不可剥夺：锁不能被抢走
4. 循环等待：A 等 B、B 等 A，形成环

破坏任一条件即可预防（最常用：固定加锁顺序，破坏循环等待）。

## 处理策略
预防（破坏条件）、避免（银行家算法）、检测（资源等待图）、恢复（回滚/杀线程）。

## 同步原语对比
| 原语 | 特点 |
|------|------|
| mutex | 抢不到就睡眠，让出 CPU |
| spinlock | 抢不到就空转，临界区极短时用 |
| rwlock | 多读单写 |
| semaphore | 计数，控制并发数 |
| condition_variable | 等条件不烧 CPU |

## 面试高频题
**Q: mutex vs spinlock？**
A: mutex 睡眠让出 CPU，spinlock 空转；临界区短用自旋锁，长用互斥锁。

**Q: 你遇到过死锁吗？**
A: 讲 Threadpool 析构：锁内 join，worker 唤醒后要拿锁才能退出，主线程持锁等 join → 互相等。解决：join 移出锁外。
