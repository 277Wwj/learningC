# 内存管理

一句话：虚拟内存让每个进程有独立地址空间，靠页表翻译、TLB 加速。

## 虚拟内存
- 每个进程以为自己独占整块内存，由 OS 映射到物理内存
- 三大好处：隔离、共享、保护

## 页表与地址翻译
- 虚拟地址分页（通常 4KB），页表记录"虚拟页 → 物理页"
- 多级页表省空间；TLB 缓存最近映射加速翻译

## 缺页中断
访问的页不在物理内存 → 陷入内核 → 从磁盘换入 → 更新页表 → 重新执行指令。

## malloc 底层
- 小内存（<128KB）：brk 扩展堆顶
- 大内存（≥128KB）：mmap 映射
- 分配器（ptmalloc/tcmalloc/jemalloc）管理空闲链表，减少系统调用

## 栈 vs 堆
| | 栈 | 堆 |
|---|----|----|
| 管理 | 编译器自动 | 手动 new/malloc |
| 大小 | 小（8MB/线程） | 大 |
| 速度 | 快 | 慢 |

## 面试高频题
**Q: mmap 是什么？**
A: 把文件映射到内存，访问内存即访问文件，是零拷贝（sendfile）的基础。
